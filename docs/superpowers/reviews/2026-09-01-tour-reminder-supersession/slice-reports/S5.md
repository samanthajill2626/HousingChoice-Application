The poll DEFERS a rung whose tour holds a `pending:` sentinel; Send now does
NOT - today it sends, and this slice deliberately left that unchanged.

The honest minimal contract is that Send now refuses only on a POINTER MISMATCH,
which is a fact about stored state; a claim in flight is a fact about a request
that is in the middle of deciding this rung's fate. Neither token is exact for
it: `superseded` is false (the ladder is intact) and `conversion_stalled` is
false inside the window (the claim has not stalled yet). The window is
sub-second to minutes, the operator has to click inside it, and the spec (3.3)
names only the POLL's deferral. Recorded rather than invented; if the reviewer
wants it closed, it needs a third token and a fifth walk of the census.

   switched off.
