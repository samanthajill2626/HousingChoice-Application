The plan's `handleFallbackSubmit` uses `Omit<HousingFairInput, 'unitId'>`,

BINDING:

  fallback sign-up never carries `housingAuthority`, which the server

  undefined }` leaves an own `unitId` key: Vitest `toHaveProperty` counts
  own keys, so `expect(arg).not.toHaveProperty('unitId')` would fail.
