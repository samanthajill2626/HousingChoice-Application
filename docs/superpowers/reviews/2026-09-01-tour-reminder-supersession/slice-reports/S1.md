## 5. THE SHIPPED CONTRACT for downstream slices

Byte-for-byte, as they now stand.

### `app/src/repos/tourRemindersRepo.ts`

`TourReminderItem` gains, between `skipReason?` and `createdAt`:

```ts
  ladderId?: string;
```

`create`'s inline input type on the interface:

```ts
  create(input: {
    tourId: string;
    kind: ReminderKind;
    dueAt: string;
    skipped?: { at: string; reason: ReminderSkipReason };
    /** The arming call's generation id (see TourReminderItem.ladderId). Omitted
     *  leaves the attribute ABSENT - the pre-migration shape, never written
     *  empty. */
    ladderId?: string;
  }): Promise<TourReminderItem>;
```

Copied in the implementation with the file's conditional-spread idiom, placed
AFTER the `skipped` spread and before `createdAt`:

```ts
        ...(input.ladderId !== undefined && { ladderId: input.ladderId }),
```

New interface member, declared immediately after `cancelForTour`:

```ts
  deleteSupersededForTour(tourId: string): Promise<void>;
```

Semantics S8/S9 must rely on:

- filter is `r.sentAt === undefined` ONLY - pending, operator-canceled and
  skipped all deleted; every `sentAt` row survives with its `sentBody`.
- each delete carries `ConditionExpression: 'attribute_not_exists(#sentAt)'`
  (`#sentAt` aliased), so a row that gains `sentAt` between the list and the
  delete SURVIVES.
- NEVER throws. A CCFE per row -> `log.debug`; any other per-row error ->
  `log.error({ err, tourId }, 'tour reminder sweep: unexpected error on row')` and
  the batch continues. One summary `log.info({ tourId, deleted }, 'superseded
  tour reminders deleted')`.
- inherits `listByTour`'s UNPAGINATED 1 MB read.
- ZERO callers today, as the slice-order safety property requires.

Claim guards, now on `claimSend`, `claimSkip` and `cancel` (NOT `uncancel`):

```ts
            ConditionExpression:
              'attribute_exists(reminderId) AND attribute_not_exists(#sentAt) AND ' +
              'attribute_not_exists(#canceledAt) AND attribute_not_exists(#skippedAt)',
```

Bare key name, no `#` alias, string-concatenation line break - the form at
`app/scripts/retire-paused-tour-reminders.ts:205-207`.

Import block: `DeleteCommand` added in alphabetical position; the never-used
`GetCommand` removed (see section 6).

### `app/src/repos/toursRepo.ts`

`TourItem` gains, between `convertible?` and `createdAt`:

```ts
  currentLadderId?: string;
```

New interface member, declared immediately after `releaseConversionClaim`:

```ts
  setLadderIdIf(tourId: string, expected: string, next: string): Promise<boolean>;
```

Implementation, immediately after `releaseConversionClaim`:

- `UpdateExpression: 'SET #cl = :next, #updatedAt = :now'`
- `ConditionExpression: 'attribute_exists(tourId) AND #cl = :expected'`
- `ExpressionAttributeNames: { '#cl': 'currentLadderId', '#updatedAt': 'updatedAt' }`
- returns `true` on a win (and bumps `updatedAt`), `false` on
  `ConditionalCheckFailedException` - **never throws for a lost compare** -

  against DynamoDB Local), so a pre-migration tour cannot be pointed by this
  method. S3 must rotate first, then CAS.
- `log.debug` on the loss, `log.info({ tourId }, 'tour ladder pointer advanced')`
  on the win. The caller (S3 T3.3) owns the `log.error`.
