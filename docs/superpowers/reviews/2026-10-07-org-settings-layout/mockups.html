Housing authorities & agencies - layout options

Static mockups for the 2026-10-07 design review. Each option shows the admin view at desktop width (left) and the same content at phone width (right). The non-admin view is the same minus the row menu (Option A), the panel's admin buttons (Option B) or the card menu (Option C). The data is the seeded starting list, plus the eight off-list values planted for the review.

Option A - Row menu, wide tab, tidy cells Recommended

Keep the tables. This tab gets a wider panel (about 1280px), and both tables share fixed column widths. Each row keeps one visible action, Edit notes, which everyone can use. The five admin actions move into a ⋯ More actions for <name> row menu, with Delete split off below a divider. Spellings render as chips and notes are clamped to two lines with a More link. "Used by" leaves out zero counts. In "Not on the list", each row's choices move into one Settle menu. A count in the status strip links down to "Not on the list".

Desktop, 1280 (panel is about 1000px here; at 1920 it grows to 1280)

Each stacked row is still a table row: the table keeps its row and column semantics, and below 768px the cells render as label/value pairs. No horizontal scroll, and the name stays on screen beside its menu.

Option B - List and detail panel

A compact list on the left shows each entry's name and use total. Selecting a row opens a detail panel on the right with everything about that entry: editable spellings chips, full notes, the usage breakdown and labeled admin buttons. "Not on the list" works the same way: the panel shows the records and the settle choices as a radio group with one confirm. This reuses the two-pane shell (ui/twoPaneShell; AI run log already uses a list and detail layout). It uses a wide screen best, but it hides spellings and notes behind a click.

Desktop, 1920 (panel is about 1280px)

Option C - Three views and cards

A segmented control at the top switches between Housing authorities, Agencies and Not on the list, each with a count and a search box. Each entry becomes a card showing its name, spellings chips, a notes line, its usage and a ⋯ menu. "Not on the list" becomes its own view, so it is no longer under 2,600px of reference rows. Cards reflow naturally at any width, but they are less scannable than table columns once the list grows toward the 300 entries D13 allows.
